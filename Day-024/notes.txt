How does Machine Learning work?
1, Train ML model, using existing labeled data.
ex: spam is labeled as spam
In this, the model learns the relationship of the attributes of the data and the outcome.
2, Then, make predictions on new data for which the label is unknown.

Iris Dataset:-
Dataset made using 150 samples of Iris flower
-> it has sepal length, width
petal length, width
ML Terms
row => observation / sample / example / instance / record
column => feature / predictor / attribute / input / regressor / covariate
each predicted value => response / target / outcome / label value
Two types of Supervised learning
Classification
-> response is categorical
Regression
-> Response is ordered and continuous
Requirements for working with data in Scikit-learn
1, Features and responses are separate objects
2, Features and responses should be numeric
3, Features and response should be in np.arrays
4, Features and responses should have specific shapes
-> Features -> first dim -> rows = no. of observations
-> second dim -> columns = number of features (attributes)
-> Responses -> only one dim -> number of observations
(Types of target)
(one for one observation)
This data set is used to find the Iris species with length and width of sepals and petals
hence supervised learning
