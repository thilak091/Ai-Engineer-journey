This is called CROSS-VALIDATION
Steps for K-fold cross-validation
1, Split the Dataset into K equal partitions (or "folds") of equal size.
2, Use fold 1 as testing set and the union of others as the training set.
3, Calculate Testing Accuracy
4, Repeat Step 2 and 3 K times, using a different fold as the testing set each time.
5, Use the average testing accuracy as the estimate of out of sample accuracy.
This allows us to find the Best Model for our data.
to import Kfold
from sklearn.cross_validation import KFold
kf = KFold(data, n_folds=num, shuffle=False)
Cross Validation Recommendations:-
1, K can be any number, but K=10 is generally recommended.
2, For classification problems,
Stratified sampling is recommended for creating folds.
-> Each response should be represented with equal proportions in each of the K Folds.
-> scikit-learn's cross_val_score function does this by default.
