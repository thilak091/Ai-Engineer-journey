AI STUDENT PLACEMENT PREDICTOR
===============================

PROJECT REQUIREMENTS
--------------------
Python 3.9+ recommended.

Install the required libraries:

    pip install pandas numpy scikit-learn


PROJECT FILE STRUCTURE
----------------------
Keep the files in the following structure:

    project-folder/
    |
    |-- placement_predictor.py
    |-- student_placement_dataset.csv
    |-- instructions.txt

The Python file and CSV dataset must be in the same folder unless you
change the CSV path in the Python code.


DATASET FORMAT
---------------
The dataset must be a CSV file named:

    student_placement_dataset.csv

Required columns:

    student_id
    gender
    department
    internship
    cgpa
    projects
    python_score
    aptitude_score
    communication_score
    placement

Example row:

student_id,gender,department,internship,cgpa,projects,python_score,aptitude_score,communication_score,placement
1,Male,AI&DS,Yes,8.42,4,86,78,82,Yes

IMPORTANT:
- Do not rename or remove the required columns.
- Numeric columns must contain numeric values.
- gender, department and internship are categorical columns.
- placement must contain only "Yes" or "No".
- Avoid missing values unless the preprocessing code is modified to handle them.


HOW TO RUN
----------
1. Clone/download the repository.
2. Put student_placement_dataset.csv in the same folder as the Python file.
3. Install the required libraries.
4. Open a terminal in the project folder.
5. Run:

    python placement_predictor.py


WHAT THE PROGRAM DOES
---------------------
The program:

1. Loads the student dataset.
2. Displays basic dataset information.
3. Separates numerical and categorical features.
4. One-hot encodes categorical features.
5. Standardizes numerical features.
6. Uses a Scikit-learn Pipeline.
7. Trains a Logistic Regression model.
8. Evaluates the model using:
   - Training Accuracy
   - Testing Accuracy
   - 5-Fold Cross Validation
   - Precision
   - Recall
   - F1-Score
   - Classification Report
   - Confusion Matrix
9. Creates a custom student profile.
10. Predicts whether placement is likely.
11. Displays the estimated placement probability.


CUSTOM STUDENT DATA
-------------------
Custom student information must follow the expected format:

    Gender: Male/Female
    Department: AI&DS/CSE/IT/etc.
    Internship: Yes/No
    CGPA: numeric value
    Projects: integer/numeric value
    Python Score: numeric value
    Aptitude Score: numeric value
    Communication Score: numeric value

Example:

    CGPA = 8.42
    Projects = 4
    Python Score = 86
    Aptitude Score = 78
    Communication Score = 82


IMPORTANT MODEL NOTE
--------------------
This is an educational Machine Learning project.

The prediction is NOT a guarantee of actual placement.

The dataset is relatively small and may contain class imbalance.
Therefore, accuracy should not be considered by itself. Precision,
recall, F1-score, the confusion matrix and comparison against a baseline
should also be considered.


TROUBLESHOOTING
---------------
FileNotFoundError:
Make sure student_placement_dataset.csv is in the same folder as the
Python script.

ModuleNotFoundError:
Install the required libraries:

    pip install pandas numpy scikit-learn

Unexpected categories:
Make sure categorical values match the dataset. The OneHotEncoder uses
handle_unknown='ignore', so unseen categories should not normally cause
the pipeline to fail.

Poor model performance:
This does not necessarily mean the code is broken. Performance depends
on the dataset, features, class balance and train/test split.
