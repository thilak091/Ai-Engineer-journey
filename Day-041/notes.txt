Easy way to fill missing values:-
Using SimpleImputer
we can fill mean, median, etc for null values
ex:-
from sklearn.impute import SimpleImputer
imp_mean = SimpleImputer(strategy = 'mean')
imp_mean.fit_transform(df)

gives an array
