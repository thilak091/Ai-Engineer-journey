Automatic Loss function
Torch's Neural Network module provides a MSELoss() method to give the loss function
ex:-
from torch import nn
loss = nn.MSELoss()
training Loop
for i in iters:
l = loss(y, y_pred) # calculating loss
Automatic weights Upgrade (Optimizer)
torch has optimizer that helps us automatic weight updates
ex:-
optimizer = torch.optim.SGD([w], lr=learning_rate)
[w] -> all params to be updated
lr -> learning rate
in Loop
for i in Loop:
# loss
l.backward()
optimizer.step() # update
optimizer.zero_grad() # cleaning gradients
